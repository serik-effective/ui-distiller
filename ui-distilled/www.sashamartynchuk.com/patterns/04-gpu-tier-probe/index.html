GPU tier probe

loading · responsive — trigger: page load; re-run with the button

Decide what to render before rendering it.

Asking navigator.hardwareConcurrency is not enough: a machine can report eight cores and still be rasterising WebGL in software, where a heavy scene collapses to single figures. This probe opens a context that refuses to be created under a major performance caveat, reads the unmasked renderer string, matches it against the known software rasterisers, and only then picks a tier — all inside a worker so the main thread never blocks on it.
