Drag-spring 3D object

3d · scroll · motion — trigger: drag the object, then scroll
WebGL or the Three.js CDN is unavailable, so this demo cannot render. Everything else about the pattern is in the README.

Scroll turns it. Drag tilts it. Let go and it springs back.

Two independent rotation sources are summed each frame: a scroll-scrubbed base angle and a spring-integrated pointer tilt clamped to ±25°.

The camera is orthographic and its frustum is rebuilt from the container's aspect ratio, so the object keeps its size and never distorts — which is why it can be dropped into any layout slot.
