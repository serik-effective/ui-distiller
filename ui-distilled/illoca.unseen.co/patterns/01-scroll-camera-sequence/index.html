Scroll. Each section below scrubs one segment of a single baked camera animation — the same wiring the source site uses, with the segment boundaries read from the keyframes themselves.

Segment 01

One track, cut into sections.

The camera has a single animation. The page does not restart it per section — it hands each section one segment of it, between two keyframes, and lets the scroll position inside that section scrub it.

Segment 02

The keyframes decide the cuts.

The segment boundaries are read from the animation itself, not hand-written. Add a keyframe and there is one more segment to hand out; the page structure follows the track.

Segment 03

Reverse is exact.

Nothing is accumulated. Progress is recomputed from geometry on every frame, so scrolling back walks the same path in reverse with no drift.

Segment 04

The pointer rides on top.

A lerped pointer offset tilts and rolls the camera around wherever the track has put it — parallax that never fights the scroll, because it is applied after the track pose.
