# Библиотека UI-эффектов

**40 интерактивных демо с 9 сайтов.** [Открыть все эффекты](../index.html) · [База JSON](../database.json) · [Проверка](verification.md) · [Выбор сайтов](selection.md).

В общем каталоге эффекты представлены вместе. Фильтр выбирает сайт, поиск работает по названию, описанию и механике. У каждой карточки есть превью, ссылка на самостоятельное демо и разбор реализации. Из демо можно вернуться во всю базу.

36 демо работают без сети; 4 используют внешние ресурсы. Каталог можно открыть как файл или запустить из корня репозитория:

```sh
python3 -m http.server 8877 --bind 127.0.0.1
```

Затем открыть `http://127.0.0.1:8877/index.html`.

HTML и разборы находятся в `ui-distilled/<host>/patterns/`, индекс каждого сайта в `patterns.json`. Общий `database.json` и каталог генерируются из этих индексов. Русские названия и описания хранятся в `assets/library-labels.ru.json`, шаблон каталога в `assets/library-template.html`.

```sh
node scripts/library.mjs
```

Генератор требует Node 18+, не использует внешние пакеты и принимает необязательный путь к корню репозитория. Для добавления сайта нужен `patterns.json`, самостоятельные демо, разборы и `preview.jpg` у каждого эффекта.

Демо воспроизводят механику интерфейсов собственной графикой и текстами. Девять эффектов Yaas Energy, Patmos и Odyssée имеют fidelity=approximate; у остальных сохранены исходные оценки. Отличия описаны в README каждого эффекта.
