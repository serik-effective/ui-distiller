# Проверка библиотеки

Девять демо Yaas Energy, Patmos и Odyssée прошли статическую проверку UI Distiller и функциональную проверку в Chrome/Playwright. [Протокол](verification/browser-verification.json).

Условия: `file://`, сеть отключена, viewport 1440×900 и 390×844, отдельная загрузка с `prefers-reduced-motion: reduce`.

| Демо | Проверенное действие |
|---|---|
| Объекты собираются в ряд | Прокрутка меняет расположение объектов, WebGL доступен |
| Дуга превращается в карточку | Переход между прокруткой дуги и раскрытием центральной карты |
| Карточки уходят из стопки | Прокрутка переключает карточки |
| Упругая бесконечная галерея | Колесо меняет offset, движение указателя деформирует поверхность |
| Индекс заменяет сцену | Выбор индекса меняет сцену |
| Изображения ↔ текстовый индекс | Переключение режима и превью строки |
| Меню с контекстным превью | Открытие, смена превью, Escape, возврат фокуса |
| Раскрытие с обратным растяжением | Reveal и восстановление scaleX до 1 |
| Редакционная лента с фокусом | Автоматический выбор третьей карты, пауза |

У всех девяти проверены тема, повторный запуск и уменьшенное движение. Ошибок JavaScript и сетевых запросов не обнаружено; горизонтального переполнения при ширине 390px нет. [Отдельная проверка фаз дуги](verification/arc-final-check.json).

31 существующее демо прошло smoke-проверку в Chrome: страницы загрузились, превью созданы, page errors отсутствуют. Полный повтор интеракций этих эффектов не проводился. [Протокол](verification/library-smoke.json).

Общий каталог проверен отдельно: 40 карточек, девять фильтров с правильными количествами, поиск, отсутствие отметок «Сегодня», загрузка всех превью и доступность локальных ссылок. Горизонтального переполнения при ширине 390px нет. [Протокол каталога](verification/catalog.json).

Все девять добавленных реконструкций имеют fidelity=approximate. Canvas2D у Patmos заменяет GPU mesh, графика и материалы процедурные, а FLIP при переключении вида является интерпретацией. Диагностические сравнения снимков не означают процент точности. Физические мобильные устройства и производительность production-интеграции не тестировались.
